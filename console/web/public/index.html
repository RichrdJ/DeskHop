Veelgestelde vragen

Welke code moet ik doorgeven?

Na het openen van het programma zie je een ID (een reeks cijfers) en een eenmalig wachtwoord. Geef deze twee door aan je supportmedewerker. Het plaatje op deze pagina is alleen een voorbeeld en bevat géén echte code.

Kan de supportmedewerker later nog meekijken?

Nee. Het eenmalige wachtwoord verandert na elke sessie en zonder dat het programma open staat kan niemand verbinden.

Hoe stop ik de sessie?

Klik in het venster van het programma op Verbreken, of sluit het programma. De verbinding stopt dan direct.

Mijn Mac vraagt om toestemming

macOS vraagt de eerste keer toestemming voor Schermopname en Toegankelijkheid. Open Systeeminstellingen → Privacy en beveiliging, zet de app bij beide aan en start hem opnieuw.

Windows waarschuwt bij het openen

Zie je een blauw scherm met “Windows heeft uw pc beschermd”? Klik op Meer info en daarna op Toch uitvoeren.
